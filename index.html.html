About PixelPlay Arcade

PixelPlay Arcade is a static, premium-feeling 2D browser arcade. Every game in the PixelPlay Originals collection is an original implementation written directly into this website's single JavaScript file — no third-party engines, no tracking, no accounts.

How it works

The site loads its catalog from a single games.json file. Built-in games run on an HTML5 canvas. Authorized third-party games can be embedded as iframes when the provider explicitly permits embedding.

Our rules

  • We only embed games that explicitly permit embedding.
  • We never bypass paywalls, anti-bot protection, or licence restrictions.
  • We never republish third-party game files without permission.

Privacy Policy

PixelPlay Arcade is a static website. It does not run a backend and does not create accounts.

Data we store

Your favorites and recently played list are stored in your browser's localStorage under the keys pixelplay.favorites.v1 and pixelplay.recent.v1. This data never leaves your device and can be cleared at any time from the Recently Played page or your browser settings.

Third-party embeds

If a game is provided by a third-party embed, that provider may set its own cookies once you start the game. Games are only loaded after you press Play.

Analytics

This build ships with no analytics or tracking scripts.
