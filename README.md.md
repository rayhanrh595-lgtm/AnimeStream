# AnimeVerse — Vanilla HTML / CSS / JS Anime Streaming Frontend

A premium dark-themed anime discovery + playback frontend built with **semantic HTML5, modern CSS3 and vanilla JavaScript ES modules**. No frameworks, no build step.

> **Legal notice:** this project ships **no video content**. Metadata comes from public APIs. Playback must be connected to a provider you are licensed to use. AnimeVerse never scrapes, proxies, re-hosts or de-obfuscates copyrighted streams.
